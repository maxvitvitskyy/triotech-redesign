# Triotech — оновлений дизайн

Візуальне переосмислення сайту triotech.ua. **Структура, тексти й фотографії
лишились ті самі**, палітра та шрифт — оригінальні брендові. Переписано те, як
сайт виглядає: сітка, типографіка, кнопки, іконки, картки, навігація, форми.

Поряд лежить `triotech-live-copy` — точна копія чинного сайту. Зручно
відкрити обидві версії поруч і порівняти.

## Що змінено і чому

| Було | Стало | Причина |
|---|---|---|
| Біла шапка з великим помаранчевим блоком телефону | Темне скло, тихий телефон, одна помаранчева дія «Залишити заявку» | Помаранчевий блок телефону перебивав головну дію. Тепер акцент один |
| Перемикач мов — прапори США й України | Текстовий `UA / EN` | Прапор ≠ мова: англійською говорять не лише у США. Текст читається однозначно |
| Заголовки секцій — `<button class="no-click">` у рамці | Справжні `<h2>` з вогняною рискою | Виглядало як кнопка, але не натискалось. Плюс заголовки тепер у структурі документа |
| Текст геро лежав просто на фото | Градієнтна завіса під текстом | Другий рядок опису налізав на техніку і не читався |
| Круглі мініатюри галузей, обрізані краєм екрана | Рейка з трьох галузей із фірмовим знаком | Мініатюри виглядали як зламаний елемент. Тепер видно, де ти є і куди перейти |
| Помаранчева плашка під кожним фото товару | Темна картка, вогняна лінія та стрілка при наведенні | Плашки були того ж кольору, що й кнопки, — усе кричало однаково |
| Чотири суцільні помаранчеві плити «Чому ми» | Темні панелі з вогняною іконкою | Найгучніший блок сторінки не був закликом до дії |
| Іконки: людина, крапля, палець, вантажівка | Один набір: манометр, бочки, щит, тягач | Різностильна кліпарт-збірка. Новий набір — одна сітка, одна товщина лінії, з галузі |
| Логотипи партнерів у власних кольорах на темному | Білі силуети, колір повертається при наведенні | Логотип FORX був майже невидимий, у TIS була біла підкладка — стіна виглядала як каша |
| Білі поля форм без підписів | Темні поля з підписами й помаранчевим фокусом | Placeholder зникає, щойно почав писати. Тепер поле лишається підписаним |
| Помаранчева плита в підвалі, «© 2022» | Спокійний підвал, рік рахується сам | Дата була застаріла на три роки |
| Помаранчеві трикутники, врізані в кути секцій | Прибрано | Декор без сенсу, який ще й налізав на форму |

Фірмовий знак — трикутник із трьох трикутників — тепер працює як орієнтир:
у геро світиться той кут, що відповідає поточній галузі.

## Виправлені помилки, успадковані від оригіналу

- `main.js` падав на головній (`Cannot read properties of null`), бо шукав
  елементи, яких там немає. Додано перевірки.
- Клік по логотипу або активному пункту меню валив скрипт і нічого не робив —
  тепер прокручує вгору.
- Посилання на PDF (`href='/doc/...'`) були абсолютні й ламались у підпапці.
- У рейці галузей активною завжди була «Військова», навіть на інших сторінках.
- Заголовок «Товари» на трьох сторінках був іншим тегом, ніж на решті.
- Секція товарів звалась то `.product`, то `.products`.
- П'ять `<h1>` на сторінку (в підвалі теж) — лишився один.
- `id="email"` повторювався двічі на сторінці.
- `<html lang="en">` стояв і на українських сторінках.
- Кнопки-піктограми (бургер, закриття, підписка) не мали доступних імен.

## Доступність

- Контраст усього тексту — не нижче AA (`--faint` піднято з `#6C7A89` до `#8592A1`).
- Видимий фокус на всіх інтерактивних елементах.
- `prefers-reduced-motion` вимикає анімації.
- Кожне поле форми має підпис, кожна піктограмна кнопка — `aria-label`.

## Структура

```
index.html · Home/en/index.html          головні (UA / EN)
Military|OilGas|Industrial/index.html    галузі (UA)
Military|OilGas|Industrial/en/index.html галузі (EN)
404.html

css/style.css        зібраний стиль
css/_parts/          вихідні частини:
  00-fonts.css         @font-face (оригінал)
  01-normalize.css     normalize.css (оригінал)
  50-site.css          ← увесь редизайн живе тут
  99-swiper.css        Swiper (оригінал)
js/main.js           оригінальний скрипт + виправлення падінь
js/ui.js             поява блоків, рік, кнопка заявки в шапці
img/ fonts/ doc/ vendor/
```

Редагувати стилі треба у `css/_parts/50-site.css`, потім зібрати:

```bash
cat css/_parts/00-fonts.css css/_parts/01-normalize.css css/_parts/50-site.css css/_parts/99-swiper.css > css/style.css
```

## Публікація

```bash
git remote add origin https://github.com/<user>/<repo>.git && git push -u origin main
```

Settings → Pages → Deploy from a branch → `main` / `(root)`.
Усі шляхи відносні — працює і в підпапці, і на власному домені.

Форми, як і в копії, відкривають поштову програму: GitHub Pages не приймає POST.
`robots.txt` закриває сайт від індексації — видали файл, якщо це бойова версія.

## Правки після першого показу

- **Іконки вбудовано в сторінки.** Раніше вони бралися з окремого файлу
  `img/sprite.svg`. Такий спосіб працює лише коли сайт відкритий через сервер —
  якщо відкрити HTML прямо з диска (подвійним кліком), браузер блокує
  завантаження і всі іконки зникають: контакти, соцмережі, підписка, стрілки
  на картках товарів. Тепер набір іконок лежить усередині кожної сторінки й
  показується завжди.
- Кольори іконок тепер задаються стилями (раніше були жорстко вшиті у файл
  спрайта, тож помаранчевий колір іконок контактів не спрацьовував).
- **Кнопки в геро помінялись акцентом:** «Залишити заявку» стала яскравою,
  «Детальніше» — спокійною.
- Стрілки додано на всі кнопки, де їх бракувало: «Залишити заявку», кнопка
  в шапці, кнопка у смузі заклику, кнопки під товарами й у формах.
- Порядок перемикача мов вирівняно: **UA / EN** в обох мовних версіях
  (раніше на англійських сторінках було EN / UA).
- `404.html` більше не залежить від зовнішніх файлів — вона віддається
  з будь-якої адреси, тож шрифт та іконка в ній замінені на вбудовані.

> Якщо сайт публікується не на власному домені, а у підпапці
> (`user.github.io/repo/`), у `404.html` два посилання на головну потрібно
> дописати як `/repo/`. Решта сторінок працює в підпапці без змін.
